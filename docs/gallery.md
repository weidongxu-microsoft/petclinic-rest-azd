# Gallery submission

Prepared for the [Awesome azd contributor guide](https://azure.github.io/awesome-azd/docs/contribute).
These assets do not submit or publish a gallery listing.

1. Append [gallery-entry.json](gallery-entry.json) to `website/static/templates.json`
   in `Azure/awesome-azd`.
2. Copy [architecture.png](images/architecture.png) to
   `website/static/templates/images/petclinic-rest-azd.png`.
3. Open a gallery pull request. The entry includes attribution, a UUID, and registered
   language, framework, Azure service, and IaC tags.

The [SVG source](images/architecture.svg) is editable.
